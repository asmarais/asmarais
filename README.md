### Featured Projects

**[Claimora AI](https://github.com/asmarais/automate-or-die)**
Trilingual French/Arabic/Derja AI assistant for Tunisian auto-insurance claims, built during a hackathon. Uses a guarded RAG architecture where the backend deterministically controls factual decisions while the LLM handles natural-language interaction. Includes Groq Whisper transcription, vision-based damage analysis, and explainable risk scoring.

**[Agentify](https://github.com/asmarais/Agentify)**
AI-powered insurance assistant combining recommendation models, LangGraph agentic workflows, and Llama 3.2 via Ollama to analyze client data, recommend insurance products, and generate personalized commercial pitches. Includes conversational pitch refinement and client analytics through a FastAPI backend.

**[RailMind](https://github.com/ouemnaa/rail-mind)**
Team project for AI-assisted railway operations, combining XGBoost prediction, Qdrant semantic search, LLM agents, and mathematical optimization for conflict detection and resolution. Achieved 87% AUROC on conflict prediction. My contribution: frontend development and system integration.

**[PFE Management Platform](https://github.com/bahaell/PFE_Management_Platform)**
Team project for graduation project management using a microservices architecture with Spring Boot, Eureka, PostgreSQL, RabbitMQ, and Docker.
